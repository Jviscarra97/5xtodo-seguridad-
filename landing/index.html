El proyecto

El Rincón de 5 conecta a tres tipos de personas: Ana Quispe, clienta que quiere comprar y seguir sus pedidos; Don Ramiro Condori, revendedor que compra para vender; y el administrador de la tienda.

Para que cada uno acceda solo a lo suyo, el subsistema Seguridad resuelve el RF01 (registro e inicio de sesión con correo o celular) y el RNF04 (control de acceso por rol), con un CRUD completo de usuarios.

Cada rol, lo suyo

HU11 · El menú y la API solo exponen lo que corresponde a cada perfil.

Cliente

Compra y gestiona únicamente su propia cuenta.

Revendedor

Compra para vender. Edita solo sus datos.

Repartidor

Rol operativo creado por el administrador.

Administrador

Gestiona todos los usuarios y asigna roles.

Seguridad desde el diseño

Reglas pensadas para proteger los datos de quienes compran en la tienda.

  • Contraseñas con hash bcrypt, nunca en texto plano.
  • Mínimo 8 caracteres con letras y números.
  • Celular boliviano de 8 dígitos que empieza con 6 o 7.
  • El autoregistro solo permite cliente o revendedor.
  • Cuentas desactivadas o eliminadas pierden el acceso al instante.
  • El administrador no puede eliminarse ni quitarse el rol a sí mismo.
  • Correo y celular únicos; al menos uno por cuenta.

Cómo ejecutarlo

Requiere Node.js instalado. Abre dos terminales:

# Terminal 1 — API en http://localhost:3001
cd backend
npm install
npm start

# Terminal 2 — Interfaz en http://localhost:5173
cd frontend
npm install
npm run dev

Al primer arranque se crea un administrador inicial: admin@5xtodo.bo / Admin1234. Cámbiala antes de desplegar y define tu propio JWT_SECRET.
